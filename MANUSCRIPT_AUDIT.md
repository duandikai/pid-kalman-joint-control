# Manuscript numerical audit

The new implementation is a reconstruction from the revised manuscript's
explicit settings and the archived original plant code. It is not evidence
that the old manuscript's figures and tables were generated by this program.
No source that generated the revision's reported values was available.

The verification checks passed, but only 22 of 60 audited numbers match the
manuscript's displayed rounding. No tuning or random-seed search was used to
obtain agreement. In particular, this run uses a newly deposited Octave seed-42
noise realization. The original random sequence, some analysis definitions,
and other implementation details are not fully recoverable from the draft.
Their contribution to each numerical difference has not been established.

## Changes from the original program

- PID gains: (8,20,0.8) -> (25,20,5), following the revised Table 1.
- Gyroscope: angle-like channel -> angular-rate measurement; H becomes I2.
- Q: diag(0.005,0.05) -> diag(5e-7,1e-4), following the revised Table 1.
- Reference angular velocity: corrected to 5*2*pi*cos(2*pi*t) deg/s.
- Added distinct encoder, LPF and KF closed loops, separate step tests, and
  all 12 sensitivity cases. The original dynamics/integration are retained.
- Separated true-state tracking errors from estimation and controller errors.
- Logged applied voltage separately from the unbounded PID command.
- Added complete CSV/MAT exports, reproducibility inputs, and audit checks.
- Added an explicit phase-estimation procedure and documented assumptions.

These are computational changes in addition to plot formatting. Changing
axis limits, splitting curves or resizing figures cannot accomplish them.

## Required author decisions before resubmission

The authors must either recover and deposit the actual source/data behind the
current manuscript, or review and adopt this reconstructed computation and
revise the manuscript's numerical statements, tables, plots and methods to
match it. The present package does not justify an assertion that it reproduces
every number in the unchanged manuscript.

For the second route, update the abstract; Sections 3.1–3.4; Tables 2/3;
Figures 1–11 as applicable; and the conclusion. Clarify the primary estimation
window, backward-Euler LPF, phase-fitting procedure, common deposited noise,
finite-horizon settling definition, and actual software used. The manuscript
also contains the phrase 'reduced phase lag ... not as reduced phase lag';
that duplicated wording needs correction. PID gain units should reflect
voltage output and radian error rather than standalone s and 1/s labels.

After the selected computation and documents agree, revise the Data
Availability Statement and response letter to identify `main.m`,
`reference_results.zip`, `DATA_DICTIONARY.md`, the input noise file and an
immutable repository version. Confirm the Zenodo archive is public and
contains that same reviewed version; its DOI was not verified in this work.
The old response letter's claims of complete reproduction and automatic
data saving did not describe the original script. This version does save
data, but the reproduction claim still requires manuscript reconciliation.

No manuscript or response-letter DOCX was changed or submitted by this code
revision. Acceptance or compliance approval remains with the journal.
